# RPN Calc (PWA)

設計計算をぱっとこなすための RPN 関数電卓。ホーム画面に追加すればアプリとして起動し、オフラインでも動きます。

公開先: https://solcf.github.io/rpn-calc-pwa/

> 以前の HEX/DEC/OCT/BIN プログラマ電卓版はタグ `v1-programmer` に残っています。

## 特長
- HP 方式の 4 段スタック（X/Y/Z/T）、LAST X、アンドゥ
- 表示形式 STD / FIX / SCI / ENG（桁数は ± で調整）。STD は小さい数も小数表示（0.00000001）
- X の下に、丸める前の値（≈）と SI 接頭辞表記（`333.3 m`、`205 k` など）を表示
- DEG モードの sin 180° や cos 90° は誤差なく 0、tan 90° はエラー
- 直径⇄半径の切替（D⇄R）、直径と角度からの弧長、直径と弧長からの角度
- ダーク / ライト / 自動（端末に合わせる）のテーマ切替、HP 35s 風の見た目（HP 35s モード）
- X をタップすると値をクリップボードにコピー
- タップで軽く振動、エラー時は 2 回振動
- 計算履歴（テープ）最新 100 件。Undo / Redo、行タップでその時点へ移動
- 状態・履歴は端末に自動保存
- オフラインファースト：起動時に通信せず、電波がなくても動作

## 画面
- 電卓画面右上の ⚙ でメニューを開きます（Android の戻るボタンで閉じる）
  - **履歴**: テープ表示、Undo / Redo、履歴の消去
  - **設定**: テーマ、HP 35s モード、角度の単位（DEG/RAD）、桁区切り、振動、PC のウィンドウサイズ固定、バージョン、最新版に更新、GitHub リンク
  - **キー説明**: 全キーの説明
- RAD モードのときは電卓画面に `RAD` の目印が出ます

## キー
| キー | 機能 | SHIFT |
|---|---|---|
| x⇄y / R↓ / LSTx | スタック操作 | R↓ → R↑ |
| ↶ | 1 つ前に戻す（入力中なら入力を取り消し）。Redo は履歴タブ | |
| sin cos tan | 三角関数（DEG/RAD は設定で切替） | 逆関数 |
| π | 円周率 | |
| 1/x x² √x | 逆数・2乗・平方根 | |
| yˣ | Y の X 乗 | |
| ˣ√y | Y の X 乗根（³√-8 = -2 も可） | |
| EEX | 指数入力（`2.1 EEX 5` = 2.1×10⁵、入力中の ± で指数の符号） | |
| log ln | 常用・自然対数 | 10ˣ / eˣ |
| D⇄R | 押すたびに元の値の ×2.0 → ×0.5 → ×1.0 と巡回（直径⇄半径の換算） | |
| 弧長 | Y=直径[mm]、X=角度[°] の弧長 π·D·θ/360（DEG/RAD 設定に関係なく度） | 角度：Y=直径[mm]、X=弧長[mm] から θ=360·L/(π·D) [°] |
| % | Y の X%（Y は残る） | Δ% = (X−Y)/Y×100 |
| CLR / CLX / ⌫ / ENTER | 全クリア / X クリア / 1文字削除・DROP / ENTER | |

### 例
| 計算 | キー |
|---|---|
| 梁の曲げモーメント wL²/8（w=12.5, L=6） | `12.5` `ENTER` `6` `x²` `×` `8` `÷` → 56.25 |
| 斜辺 √(3²+4²) | `3` `x²` `4` `x²` `+` `√x` → 5 |
| 30° の勾配の高さ（斜長 2.5） | `2.5` `ENTER` `30` `sin` `×` → 1.25 |
| 半径 25 の 90° の弧長 | `25` `D⇄R`（→50） `ENTER` `90` `弧長` → 39.27 |
| 直径 50 で弧長 39.27 の角度 | `50` `ENTER` `39.27` `SHIFT` `弧長` → 90° |

PC のキーボードでも操作できます（数字, `.`, `e`=EEX, `n`=±, Enter, Backspace, Esc=CLX, Delete=CLR, `+ - * /`, `^`=yˣ, `q`=√, `i`=1/x, `p`=π, `d`=D⇄R, `a`=弧長, `%`, `s`=x⇄y, ↑↓=ロール, Ctrl+Z=Undo, Ctrl+Y=Redo）。
キーボードの Shift を押している間は電卓も SHIFT 状態になり（離すと解除）、Shift+英字はそのキーの SHIFT 機能になります（Shift+a=角度、Shift+r=R↑）。記号キーは Shift で打つものが多いため、Shift を押していても通常の機能のままです。

## 開発

```bash
npm test                       # 計算エンジンのテスト
py tools/devserver.py          # http://localhost:8765 で確認（serve.cmd でも可。キャッシュ無効）
py tools/make_icons.py         # アイコン再生成
```

ビルド不要の素の HTML/CSS/JS です。`main` に push すると GitHub Pages に反映されます。

Service Worker は公開サイト（github.io）では**キャッシュ優先**で、起動時に通信しません（電波が弱くても即起動）。新しい版はブラウザが `sw.js` の変化を見つけたときに裏で取得し、次回起動から切り替わります。開発用（localhost / Tailscale）はネットワーク優先なので、修正がすぐ反映されます。

そのため**リリースのたびに必ず** `version.js` の `VERSION` / `RELEASED` と `sw.js` のキャッシュ名 `rpn-<VERSION>` を一緒に上げてください（上げないと公開しても端末に届きません。`npm test` が両者の一致を確認します）。

## 構成
- `core.js` — 計算エンジン（スタック、入力、演算表 `MATH`、表示形式）
- `keys.js` — キーの定義を一か所に集約（配置、ラベル、SHIFT 機能、キー説明、履歴の表記、PC キー）。キーを足すときはここ（と計算するなら `core.js` の `MATH`）だけ
- `app.js` — 画面・タッチ・キーボード・メニュー・保存
- `history.js` — 計算履歴と Undo / Redo
- `version.js` — バージョン番号
- `skin-hp35s.css` / `fonts/` — HP 35s 風スキンと液晶用ドットフォント（Doto, SIL OFL）
- `sw.js` / `manifest.webmanifest` / `icons/` — PWA
- `tools/devserver.py` / `serve.cmd` — 開発用サーバー
- `test/core.test.mjs` — エンジンのテスト
